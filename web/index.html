starwasm Starlark REPL

Try: 
Starlark, compiled to WebAssembly (GC) by a compiler written in Starlark, itself compiled to WebAssembly, all running in this page. Each input recompiles and replays the session. :help for help.
>>>
Blocks and open brackets continue on ... lines, indented as the block is (backspace dedents); end a block with an empty line. Pasting from a REPL session (lines with the >>> prompt) enters what was typed there, not what was printed. ↑/↓ history, Ctrl-L clears, Tab completes names, and after a . the fields or methods of the value's type. Type errors in what you type are marked in red; point at one for the type checker's message. The session is saved in this browser and restored when you come back; :reset clears it and the screen.
